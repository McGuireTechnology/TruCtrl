# Home

TruCtrl ("True Control") is a modern Configuration Management Database (CMDB) platform with a strong focus on security controls. It helps organizations manage, track, and secure their assets, configurations, and relationships, while providing deep visibility into security controls and compliance across your environment.

## Target Architecture

TruCtrl is designed with a modern, scalable architecture:

- **Backend:** FastAPI (Python) for high-performance APIs and business logic
- **Database:** PostgreSQL for robust, reliable data storage; SQLite for testing and local development.
- **Frontends:**
    - Web dashboard built with Vite (JavaScript/TypeScript)
    - Native Apple (macOS, iOS) app
    - Native Android app

This architecture enables secure, real-time access to your CMDB from any device, supporting both web and mobile workflows.
