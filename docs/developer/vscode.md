# VS Code

## Recommended Extensions

For the best development experience, install these VS Code extensions:

- **Python** (ms-python.python): Python language support
- **Pylance** (ms-python.vscode-pylance): Fast Python language server
- **Black Formatter** (ms-python.black-formatter): Code formatting
- **isort** (ms-python.isort): Import sorting
- **Flake8** (ms-python.flake8): Linting
- **Ruff** (charliermarsh.ruff): Fast linter
- **Mypy** (matangover.mypy): Type checking
- **Pre-commit** (ryanluker.vscode-pre-commit): Pre-commit integration
- **Material Icon Theme** (pkief.material-icon-theme): File and folder icons
- **Markdown All in One** (yzhang.markdown-all-in-one): Markdown editing
- **YAML** (redhat.vscode-yaml): YAML support for config files

These extensions help maintain code quality, consistency, and productivity.
