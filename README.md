# TruCtrl

This is the main PyPI project for TruCtrl, organized with the following subprojects:
- `api`: Python package for backend/API logic
- `web`: Web frontend (can be Python or other tech)
- `android`: Android client
- `apple`: Apple/iOS client
- `docs`: Documentation

## Development

- Python code should go in the `api` directory.
- To build the PyPI package, use the standard Python build tools.

## Structure

- `api/` - Python package (PyPI)
- `web/` - Web frontend
- `android/` - Android app
- `apple/` - Apple/iOS app
- `docs/` - Documentation
